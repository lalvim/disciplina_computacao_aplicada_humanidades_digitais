# Revisor de didática

## Pergunta central

O percurso permite que estudantes sem pré-requisitos desenvolvam as
competências previstas, com clareza, participação e carga cognitiva adequada?

## Escopo

Avaliar:

- objetivos de aprendizagem;
- sequência dos notebooks;
- clareza das explicações;
- qualidade dos exemplos;
- integração entre Markdown e Python;
- atividades formativas;
- feedback e gabaritos;
- carga de trabalho;
- avaliação do produto final.

## Critérios

### Alinhamento didático

Para cada objetivo, verificar se existe:

1. explicação;
2. exemplo;
3. prática;
4. feedback;
5. evidência de aprendizagem.

### Progressão

- conhecimentos prévios são explicitados;
- conceitos novos aparecem antes de serem exigidos;
- exemplos simples preparam tarefas mais abertas;
- a complexidade aumenta gradualmente;
- cada notebook retoma e amplia o anterior;
- o produto parcial alimenta a oficina final.

### Uso de Python

- código aparece quando há algo a experimentar;
- respostas discursivas permanecem em Markdown;
- cada operação é motivada por uma pergunta;
- a saída recebe interpretação;
- sintaxe nova é explicada antes de ser exigida;
- erro de programação não impede avaliar compreensão conceitual.

### Atividades

- instruções informam o que produzir;
- tempo estimado é plausível;
- perguntas abertas possuem critérios;
- questões objetivas evitam pistas e ambiguidades;
- feedback explica, em vez de apenas informar certo ou errado;
- revisão entre pares possui orientação suficiente.

## Teste de percurso

Simular três perfis:

1. estudante sem experiência em Python;
2. estudante com programação, mas sem formação em Humanidades Digitais;
3. estudante das Humanidades com projeto ainda amplo.

Para cada perfil, registrar:

- ponto provável de dificuldade;
- apoio existente;
- apoio ausente;
- risco de desengajamento;
- adaptação recomendada.

## Perguntas obrigatórias

1. O que o estudante deverá saber fazer ao final?
2. Há atividade correspondente a cada objetivo?
3. Algum código funciona apenas como decoração?
4. Alguma atividade aberta está sem feedback ou critério?
5. A carga cabe em oito horas?
6. Os exercícios finais medem compreensão ou apenas reconhecimento verbal?
7. A oficina final integra efetivamente os notebooks?

## Entrega

Usar `modelo_de_parecer.md` e incluir:

- mapa resumido entre objetivos e atividades;
- análise dos três perfis;
- achados por gravidade;
- estimativa de carga;
- decisão.
