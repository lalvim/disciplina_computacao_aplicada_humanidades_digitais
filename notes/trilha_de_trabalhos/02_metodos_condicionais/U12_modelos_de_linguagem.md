# U12 — Entrega condicional: modelos de linguagem

## Pergunta de aplicabilidade

Um modelo de linguagem pode ser comparado, de maneira controlada, com um método
de referência em uma tarefa já definida no projeto?

## Requisitos

- tarefa e saída esperada claramente definidas;
- método de referência mais simples;
- mesma amostra para a comparação;
- critérios de correção e utilidade;
- versão do modelo, instruções e parâmetros;
- permissão para processar os dados;
- plano de inspeção de erros, custos e instabilidade.

## Produto quando incorporado

**Experimento controlado entre modelo de linguagem e referência**, contendo:

- tarefa;
- baseline;
- protocolo de avaliação;
- resultados quantitativos e qualitativos;
- exemplos de acertos, erros e respostas não rastreáveis;
- sensibilidade às instruções;
- custo, privacidade e reprodutibilidade;
- decisão de uso, uso restrito ou não uso.

## Motivos legítimos para não adoção

- dados sensíveis ou protegidos;
- ausência de autorização para serviço externo;
- tarefa sem referência avaliável;
- custo ou acesso instável;
- método simples já suficiente;
- ausência de benefício para a pergunta humanística.

## Regra fundamental

O modelo de linguagem não substitui corpus, proveniência, leitura das fontes nem
avaliação. A comparação deve usar uma tarefa anteriormente formulada, e não criar
uma demonstração desvinculada do projeto.
