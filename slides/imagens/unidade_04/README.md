# Gráficos dos slides da Unidade 4

Os sete SVGs desta pasta são gráficos calculados a partir de
`unidade_04/dados/documentos.csv`, uma base inteiramente fictícia. Eles não
constituem evidência histórica.

Os arquivos são reconstruídos com:

```bash
python3 scripts/construir_graficos_slides_unidade_04.py
```

O script reutiliza as funções acessíveis de `unidade_04/graficos.py`, também
usadas nos notebooks. Cada SVG contém título e descrição textual. Alterações na
base ou nas funções exigem nova execução do script e revisão das interpretações
nos slides.
