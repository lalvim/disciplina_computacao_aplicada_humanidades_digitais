# Gráficos dos slides da Unidade 5

Os quatro SVGs desta pasta são calculados a partir das bases fictícias da
Unidade 5. Eles ilustram procedimentos estatísticos e textuais e não sustentam
afirmações históricas.

Reconstrução:

```bash
python3 scripts/construir_graficos_slides_unidade_05.py
```

O script reutiliza `unidade_05/graficos.py`, as sementes aleatórias registradas
nos notebooks e as mesmas convenções de comparação. Cada SVG contém título e
descrição. Alterações nos dados ou parâmetros exigem nova execução e revisão das
interpretações nos slides.
