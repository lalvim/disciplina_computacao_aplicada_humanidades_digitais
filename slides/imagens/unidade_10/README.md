# Imagens calculadas dos slides da Unidade 10

Os cinco SVGs desta pasta são produzidos por
[`scripts/construir_graficos_slides_unidade_10.py`](../../../scripts/construir_graficos_slides_unidade_10.py)
a partir dos dados inteiramente fictícios em `unidade_10/dados/`.

As figuras apresentam:

- a ambiguidade de “Santa Rita” no documento D008;
- a quantidade de menções encontradas pelo dicionário em cada tipo;
- a linha do tempo das quatro alegações extraídas por regras;
- a comparação entre predições e anotação de referência;
- o efeito de um erro de vinculação no grafo derivado.

Para reproduzir:

```bash
python3 scripts/construir_graficos_slides_unidade_10.py
```

As visualizações são materiais didáticos autorais. Não representam pessoas,
instituições ou acontecimentos históricos reais.
