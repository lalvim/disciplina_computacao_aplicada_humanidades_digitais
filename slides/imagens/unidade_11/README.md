# Imagens calculadas dos slides da Unidade 11

Os cinco SVGs desta pasta são gerados por
[`scripts/construir_graficos_slides_unidade_11.py`](../../../scripts/construir_graficos_slides_unidade_11.py)
a partir dos dados fictícios em `unidade_11/dados/`.

As figuras apresentam:

- contagem e taxa, com a ruptura de definição em 1990;
- médias móveis centradas de três e nove anos;
- menções normalizadas de “patrimônio” e “digital”;
- mapas em grade de contagens e taxas;
- o efeito de duas agregações territoriais, como exemplo de MAUP.

Para reproduzir:

```bash
python3 scripts/construir_graficos_slides_unidade_11.py
```

As visualizações são materiais didáticos autorais. A grade não corresponde a
território real e os dados não sustentam afirmações históricas ou demográficas.
