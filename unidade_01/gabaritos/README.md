# Gabaritos da Unidade 1

Esta pasta reúne materiais de apoio ao docente para correção, discussão e
devolutiva das atividades da Unidade 1.

## Organização

| Arquivo | Conteúdo |
|---|---|
| `gabarito_01_perguntas.md` | Classificação das perguntas e exemplo do produto parcial |
| `gabarito_02_operacionalizacao.md` | Exemplo de mapa de operacionalização e critérios de análise |
| `gabarito_03_corpus.md` | Resultados dos experimentos e exemplo de ficha do corpus |
| `gabarito_04_oficina.md` | Projeto-modelo integrado e rubrica de correção |
| `gabarito_exercicios_multipla_escolha.md` | Chave das 18 questões do exercício HTML |

O Notebook 00 contém um diagnóstico inicial e, portanto, não possui respostas
certas. As respostas devem ser usadas para conhecer a turma e ajustar o ritmo
das aulas.

## Tipos de gabarito

### Resposta objetiva

Aplicável quando a atividade verifica uma distinção conceitual ou uma operação
com resultado determinado. O gabarito informa a resposta e a justificativa.

### Resposta-modelo

Aplicável às atividades de formulação e interpretação. O texto apresentado é
uma possibilidade coerente, não uma formulação obrigatória. Respostas diferentes
podem ser plenamente adequadas.

### Rubrica

Aplicável ao projeto. A correção deve observar a coerência entre pergunta,
unidade de análise, corpus, operacionalização, evidência e limites, em vez de
procurar palavras específicas.

## Uso recomendado

- não distribuir os modelos antes de o estudante realizar a atividade;
- apresentar respostas objetivas após a discussão em pequenos grupos;
- usar os modelos abertos para comparar escolhas metodológicas;
- destacar que reconhecer uma limitação melhora a proposta;
- aceitar alternativas bem justificadas;
- registrar dúvidas recorrentes para revisar os notebooks.

## Limite de confidencialidade

A separação em `gabaritos/` é organizacional, não um mecanismo de segurança.
Quem tiver acesso ao repositório poderá abrir estes arquivos. Além disso, um
questionário HTML que funciona integralmente no navegador precisa conter sua
lógica de correção no próprio arquivo.

Caso seja necessário ocultar respostas em uma avaliação formal, será preciso
usar um ambiente com autenticação e correção no servidor, como o sistema
institucional de aprendizagem.
