certas. Seu gabarito oferece um exemplo de preenchimento, uma leitura docente e
uma devolutiva possível. As respostas reais devem ser usadas para conhecer a
turma e ajustar o ritmo das aulas.

## Tipos de gabarito

### Resposta objetiva

Aplicável quando a atividade verifica uma distinção conceitual ou uma operação
com resultado determinado. O gabarito informa a resposta e a justificativa.

### Resposta-modelo

Aplicável às atividades de formulação e interpretação. O texto apresentado é
uma possibilidade coerente, não uma formulação obrigatória. Respostas diferentes
podem ser plenamente adequadas.

Cada resposta-modelo inclui uma linha de raciocínio ou um exemplo de revisão.
Esses comentários tornam visíveis as decisões que ligam pergunta, fonte,
representação, operação, evidência e interpretação.

### Rubrica

Aplicável ao projeto. A correção deve observar a coerência entre pergunta,
unidade de análise, corpus, operacionalização, evidência e limites, em vez de
procurar palavras específicas.

## Uso recomendado

- não distribuir os modelos antes de o estudante realizar a atividade;
- apresentar respostas objetivas após a discussão em pequenos grupos;
- usar os modelos abertos para comparar escolhas metodológicas;
- destacar que reconhecer uma limitação melhora a proposta;
- aceitar alternativas bem justificadas;
- registrar dúvidas recorrentes para revisar os notebooks.

## Limite de confidencialidade

A separação em `gabaritos/` é organizacional, não um mecanismo de segurança.
Quem tiver acesso ao repositório poderá abrir estes arquivos. Caso seja
necessário ocultar respostas em uma avaliação formal, será preciso usar um
ambiente institucional com controle de acesso.
