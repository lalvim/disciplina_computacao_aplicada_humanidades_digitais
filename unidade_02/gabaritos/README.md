# Gabaritos da Unidade 2

Os arquivos apresentam respostas-modelo e critérios de correção. Atividades
abertas admitem outras soluções quando as decisões forem coerentes, rastreáveis
e bem justificadas.

Cada gabarito contém ao menos um exemplo preenchido. Os exemplos usam o
catálogo fictício da unidade e mostram uma linha de raciocínio possível; não
devem ser copiados como fórmula nem utilizados para produzir afirmações
históricas reais.
