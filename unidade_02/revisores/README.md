# Revisores da Unidade 2

Esta pasta define seis perspectivas de revisão. Cada parecer deve citar
evidências localizáveis, classificar a gravidade e distinguir correção
obrigatória de aperfeiçoamento.

| Arquivo | Foco |
|---|---|
| `01_nivel_academico.md` | rigor e nível de mestrado |
| `02_didatica.md` | progressão e carga |
| `03_alinhamento.md` | ementa, produto e escopo |
| `04_humanidades_digitais.md` | crítica das fontes e poder |
| `05_referencias.md` | precisão e sustentação |
| `06_tecnico_acessibilidade.md` | execução, formatos e acesso |

Os resultados ficam em `pareceres/`.
