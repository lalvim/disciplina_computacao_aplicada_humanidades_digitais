# Gabaritos da Unidade 3

Respostas abertas são modelos de procedimento, não soluções únicas. Avalie
rastreabilidade, adequação da regra, testes e reconhecimento de perdas.

Cada arquivo contém pelo menos uma resolução integralmente preenchida. O aluno
pode usar a estrutura e o nível de justificativa como guia, sem precisar reproduzir
as mesmas decisões em seu próprio projeto.
